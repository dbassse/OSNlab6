## 1. Предсказание зарплаты (Текст + Параметры)
**Файл:** `l6z1(1).ipynb`

### Описание
Задача регрессии для определения уровня заработной платы на основе данных из резюме или вакансий. Модель обрабатывает одновременно два типа данных:
* **Текстовое описание:** Обработка через `Embedding` и `Conv1D`/`LSTM`.
* **Категориальные данные:** Информация о городе, опыте работы и занятости.

**Особенности:** Использование `Functional API` для объединения (concatenate) признаков разных типов в единый вектор перед финальными полносвязными слоями.

## 2. Оценка стоимости квартир (Multi-input сеть)
**Файл:** `l6z2.ipynb`

### Описание
Более продвинутая модель для оценки недвижимости, использующая два параллельных потока обработки информации:
1.  **Текстовый поток:** Анализирует текстовое объявление (описание квартиры).
2.  **Числовой поток:** Обрабатывает параметры (этажность, площадь, удаленность от метро).

**Технологии:**
* Преобразование текста в последовательности индексов слов.
* Нормализация числовых данных.
* Объединение потоков через слой `concatenate`.
